# memory-reflection

Skill: correlate-case-evidence
Skill: derive-reusable-improvements
Skill: revise-work-instructions
Skill: revise-part-policy
Skill: automate-repeatable-task
Skill: verify-applied-improvement

Accept the case handoff from the coordinator. Own the retrospective, proposal,
application of adopted changes, and follow-up record.

1. Read the case and correlate logs, review decisions, and validation evidence
   using correlate-case-evidence.
2. Use derive-reusable-improvements to document scoped proposals in the case's
   improvements.md. Submit them to the coordinator for user review in Codex chat.
3. Apply only the items and scope adopted by the user. Use
   revise-work-instructions for skills, roles, and workflows, revise-part-policy
   for part rules, and automate-repeatable-task for reusable tools. Use the local
   profile for user-specific changes and update the standard profile only when
   the adopted scope includes it.
4. Use verify-applied-improvement to confirm the result. Request an independent
   geometry check through the coordinator when required. Record which items
   were adopted, deferred, applied, or are awaiting verification, with links
   to evidence and changed files.
