---
name: automate-repeatable-task
description: Implement a reusable tool for a repeatable case operation.
---

Check whether an existing tool or CLI can perform the operation. Use the
case evidence to identify inputs, outputs, tolerances, and the behavior to
preserve. Extend an existing tool where it fits, or add the smallest reusable
operation under tools/. Make engineering code changes on a work branch.
Verify the operation through its normal entry point using a representative
example. Store detailed CAD and generated evidence outside version control.
