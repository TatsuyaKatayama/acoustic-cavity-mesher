---
name: derive-reusable-improvements
description: Turn case evidence into scoped, testable improvement proposals.
---

For each supported observation, explain what would improve a future case,
when the change applies, and how to check it. Look for prior changes covering
the same issue. Select the smallest suitable change: procedure, role or skill
selection, workflow, part policy, or reusable tool. Record the evidence,
applicability, target, expected result, and verification method in improvements.md.
Label proposals and unresolved questions for review in Codex chat.
