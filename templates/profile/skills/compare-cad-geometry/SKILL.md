---
name: compare-cad-geometry
description: Compare original and simplified geometry using synchronized views and sections.
---

For the author self-check, compare face and edge counts, synchronized views and
relevant sections before submission. Record findings and any unavailable evidence.

For independent suitability review, finish with a same-view and relevant section
comparison of the unchanged inputs. Inspect retained boundaries, functional
openings and intended simplifications. Report what is visible and what remains
uncertain. If only some sections could be inspected, identify them and report the
remaining scope.

Use the validation report's feature measurements to compare minimum face area and
minimum nondegenerate edge length before and after simplification. Report
the face or edge indices and any features below explicitly specified limits.
Use the measured values as evidence even if no limits were specified.
